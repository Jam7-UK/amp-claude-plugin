# Security policy

## Reporting a vulnerability

Please report security issues in this plugin or in the AMP connector at `https://actions.jam7.com/mcp` by email to **compliance@jam7.com**. Do not open a public GitHub issue for a security problem.

Please include what you found, the steps to reproduce it, and the impact you expect. We aim to acknowledge reports within three working days and will keep you updated while we investigate and fix the issue.

## Scope

- The files in this repository (plugin manifest, connector configuration and skills).
- The AMP MCP server and its OAuth sign-in at `actions.jam7.com` and `os.jam7.com`.

Please do not test against other customers' data, run denial-of-service tests, or use social engineering.

## Supported versions

Only the latest release of this plugin is supported.
